# Скрейпер карточек товара (live, по артикулу)

## Задача

Клиент даёт артикул товара — нужно мгновенно вернуть полную карточку с сайта
производителя (название, фото, габариты, характеристики, опции, сопутствующие товары).
Без записи в БД — чистый live-скрейп.

## Решение

FastAPI-сервис `GET /product?article=…`:

- **Нормализация артикула** — верхний регистр + кириллица→латиница (на сайте артикулы вперемешку: `1R-В.001-15PHARM` → `1R-B.001-15PHARM`).
- **Карта «артикул → URL»** — собрана один раз (сайт ищет только по slug, не по артикулу), зашита как статический конфиг (`article_url_map.json`).
- **Обход cookie-защиты** — лёгкий beget-челлендж обходится заголовком `Cookie: beget=begetok`.
- **HTML-парсинг карточки** — извлечение названия, изображений, спецификаций, стандартных функций, областей применения, связанных товаров.

## Стек

FastAPI, httpx (асинхронно), HTML-парсер, systemd.

## Результат

- Ответ за миллисекунды (без БД, без кэша — всегда свежие данные с сайта).
- ~66 карточек в каталоге, интеграция по одному HTTP-запросу.
