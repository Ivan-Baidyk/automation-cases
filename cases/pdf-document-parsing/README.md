# Парсинг PDF-документов (self-hosted PDF → текст)

## Задача

Прайс-листы и коммерческие предложения приходят PDF-файлами (часто со сканами и таблицами).
Нужно было автоматически извлекать из них текст и таблицы для дальнейшей обработки.

## Решение

Развёрнут **self-hosted сервис на базе Docling** (с LibreOffice для офисных форматов):

- `POST /v1/convert/file` — принимает PDF (и docx/pptx/сканы), возвращает структурированный
  Markdown/JSON с извлечёнными таблицами.
- Модели грузятся при старте (`LOAD_MODELS_AT_BOOT`), работа только на CPU.
- Результат отдаётся в n8n-процесс, где LLM дораспознаёт и структурирует позиции.

## Стек

Docling (docling-serve), Docker, CPU-инференс, healthcheck.

## Результат

- Автоматическое распознавание PDF-прайсов вместо ручного переноса в таблицы.
- Стабильный конвейер «PDF → текст → LLM → позиции в БД».
