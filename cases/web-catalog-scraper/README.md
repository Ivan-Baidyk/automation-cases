# Web-каталог скрейпер (фреймворк обхода каталогов поставщиков)

## Задача

Нужно было регулярно собирать товарные каталоги с десятков сайтов поставщиков (разные
движки, антибот-защита, sitemap/JSON API/headless-рендер) и складывать всё в единую БД с
ценами, остатками и характеристиками.

## Решение

Разработан **FastAPI-сервис** — универсальный фреймворк обхода каталогов:

```
sitemap/разделы → карточки товаров → детали
   (fetch_catalog) → (fetch_product_urls) → (fetch_product_details)
```

Ключевые решения:

- **Трёхстадийный пайплайн** — каталог → список URL → детали карточек, каждая стадия идемпотентна и возобновляема.
- **Реестр парсеров** — каждый поставщик = отдельный парсер-плагин (registry), добавляется без изменения ядра (см. `HOW_TO_ADD_PARSER.md`).
- **Анти-бан** — token-bucket ограничение темпа (`rate_rps`), retry с экспоненциальной задержкой, ротация User-Agent.
- **Управление** — эндпоинты `/parse`, `/parse/resume`, `/parse/stop`, `/parse/progress` (долгие обходы возобновляемы).
- **Персистентность** — сырые страницы кэшируются (`raw_pages`), товары upsert-ятся по ключу `(supplier_id, external_id)`, цены/остатки пишутся в историю.

## Стек

FastAPI, asyncpg/async SQL, PostgreSQL, Docker, n8n (оркестратор запускает обходы по расписанию).

## Результат

- ~2,4 млн товарных позиций в едином каталоге из нескольких источников.
- Обход устойчив к банам: возобновление без повторного скачивания уже обработанного.
