# PIM / товарная база (AtroCore)

## Задача

Товарные данные приходили из многих источников (парсеры сайтов, прайс-файлы) и хранились
в разнородных таблицах. Нужна была единая управляемая товарная база (PIM).

## Решение

Развёрнут **AtroPIM** (open-source PIM на AtroCore):

- PHP + Apache + PostgreSQL, работает в Docker.
- Подключён к общей PostgreSQL (отдельная схема/роль), откуда импортируются товары из
  парсеров (brand/vendor, country, supplier, атрибуты через EAV-модель).
- Написан скрипт импорта `catalog.products → AtroPIM Product` (стандартные поля + EAV-атрибуты,
  value-колонка по типу атрибута: text→text_value, float→float_value, array→json_value и т.д.).

## Стек

AtroCore/PIM, PHP, PostgreSQL, Docker, Python (скрипт импорта).

## Результат

- Централизованная управляемая товарная база вместо разрозненных таблиц.
- Импорт сотен тысяч позиций с корректной раскладкой атрибутов.
