# Automation and Data Engineering Cases

Подборка автономных кейсов по автоматизации сбора и обработки данных, документообороту и
интеграции систем. Каждый кейс — отдельная задача с описанием, архитектурой и инструкцией
по развёртыванию (`deploy.md`).

> Кейсы обезличены: без имён клиентов, доменов и IP. Показаны технические решения и подходы.

## Стек

- **Python / FastAPI** — микросервисы, REST API
- **PostgreSQL** (+ pgvector, paradedb/BM25, pg_trgm) — хранение, векторный и полнотекстовый поиск
- **Docker / Docker Compose / systemd** — развёртывание и эксплуатация
- **n8n** — оркестрация процессов (в кейсах упоминается как связующий слой)
- **Playwright / httpx / curl_cffi** — сбор данных с сайтов
- **LLM-интеграции** (OpenRouter, DeepSeek, GigaChat) — распознавание и структурирование неструктурированных данных
- **Docling / Carbone / Gotenberg** — обработка документов (PDF → текст, генерация docx/pdf)

## Инфраструктура (фоновая)

Помимо кейсов, на том же контуре работали служебные компоненты: **1С:Предприятие** (учёт) и
**Zabbix** (мониторинг) — они описаны в общем контексте, не выделены в отдельные кейсы.
Оркестрация всех процессов — через **n8n** (процессы не публикуются, но упоминаются как
потребители API кейсов).
