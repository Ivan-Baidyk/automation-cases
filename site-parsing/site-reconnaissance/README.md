# Разведка сайтов (аудит парсибельности)

## Задача

Прежде чем писать парсер под очередной сайт, нужно было быстро понять: какой у него техстек,
есть ли sitemap и JSON API, стоит ли антибот-защита и насколько сложно его обходить.

## Решение

Сервис **трёхуровневой разведки** — принимает URL и прогоняет его через три инструмента:

1. **scrapalyser** — анализ техстека, CMS, фреймворков, заголовков/кук.
2. **api-recon** — браузерный обход (Playwright) с перехватом XHR/fetch-запросов для поиска скрытых JSON API.
3. **caniscrape** — глубокая диагностика антибот-защиты (Cloudflare, капчи, блокировки по гео/UA), оценка сложности 0–10.

Результат — структурированный JSON-отчёт, который отдаётся ИИ-агенту для принятия решения «как парсить» и прикидки трудозатрат.

## Стек

FastAPI, Playwright, httpx, subprocess-оркестрация внешних инструментов, systemd.

## Результат

- Разведка нового сайта за минуты вместо часов ручного анализа.
- Отчёт формализует решение: http-парсинг / headless / JSON API / нужен прокси.
