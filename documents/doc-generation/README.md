# Генерация документов из шаблонов (docx/pdf)

## Задача

Коммерческие предложения и договоры должны формироваться в фирменном стиле: готовый
шаблон + данные → документ (docx/pdf). Встроенная генерация в оркестраторе была нестабильной.

## Решение

Вынесена генерация в **Carbone** (self-hosted, Enterprise):

- `POST /template` — загрузка шаблона → `templateId` (криптографический id).
- `POST /render/{templateId}?download=true` — рендер документа из JSON-данных, сразу файл
  (`convertTo: pdf` — конвертация в PDF на лету).
- Рендер идёт из n8n/микросервисов через HTTP API.

## Стек

Carbone (Node.js + LibreOffice), Docker, REST API.

## Результат

- Надёжный рендер КП/договоров вместо падающей генерации внутри оркестратора.
- Один шаблон переиспользуется для всех документов одного типа.
